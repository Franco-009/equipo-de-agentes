# Ejemplo de uso

## Problema

> Necesito una pequeña aplicación que permita registrar tareas y marcarlas como terminadas.

## Architect

El Architect debería convertir esa necesidad en:

- objetivo;
- funcionalidades mínimas;
- funcionalidades fuera de alcance;
- diseño;
- pasos de implementación;
- criterios de terminado.

Después el Engineer implementaría ese plan y el Tester verificaría el resultado.

Este ejemplo es deliberadamente simple: sirve para entender el flujo antes de aplicarlo a un proyecto real.
