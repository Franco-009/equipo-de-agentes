# Equipo de Agentes

Repositorio personal de Franco para construir y reutilizar equipos de agentes de IA.

## Equipo base

- **Architect**: entiende el problema, define objetivos, restricciones y plan de trabajo.
- **Engineer**: transforma el plan en implementación.
- **Tester**: verifica la implementación, busca errores y propone correcciones.

## Flujo

```
Problema
   ↓
Architect
   ↓
Plan
   ↓
Engineer
   ↓
Implementación
   ↓
Tester
   ↓
¿Funciona?
  ↙     ↘
 NO      SÍ
 ↓        ↓
Engineer  Fin
```

## Objetivo

Empezar con agentes simples y reutilizables. A medida que los probemos en proyectos reales, se irán agregando reglas, herramientas y automatizaciones.

## Estructura

- `agents/`: instrucciones de cada agente.
- `workflows/`: formas de coordinar los agentes.
- `examples/`: ejemplos de uso.
